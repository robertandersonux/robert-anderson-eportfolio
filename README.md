# Robert Anderson ePortfolio

My personal portfolio site as a UX designer and front-end developer. It shows my projects, an About section and a contact form, plus a Habit Stacking UX case study.

## Features

- Project cards with live-site and code links
- About and contact modal, with the contact form sent through EmailJS
- Habit Stacking case study page with a downloadable PDF
- Responsive layout for phone, tablet and desktop

## Built with

HTML · CSS · JavaScript · EmailJS

## Getting started

No build step or install needed.

    git clone https://github.com/robertandersonux/robert-anderson-eportfolio.git
    cd robert-anderson-eportfolio

Then open `index.html` in your browser, or serve the folder with any local server (for example, the VS Code Live Server extension).
